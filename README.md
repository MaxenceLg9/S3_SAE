# SAE-S3S4-2024-2025-MCOI_MLAG_PSOC_VNAV
Projet de Gestion Immobilière à destination du propriétaire

Ce projet permet de pouvoir gérer un ensemble de biens immobiliers tout en pouvant
y attribuer des locataires qui peuvent être des colocataires. Afin de faciliter la
gestion des différents baux, des documents seront automatiquement générés comme la
facture. Le propriétaire peut gérer ses budgets de manière plus intuitive grâce à
cette application.
